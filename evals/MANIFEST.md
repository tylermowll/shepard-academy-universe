# Public fixture provenance

All exercises here were authored for this repository using elementary rational
arithmetic and synthetic text. No learner record, employer material, workbook
page, private photograph, credential, or downloaded model weight is included.
Application-original fixture content is MIT licensed with the repository.

| Files | Source and purpose |
|---|---|
| `fixtures/rational-v1.json` | 33 original exact answer/format/parser cases; deterministic software verification |
| `fixtures/vision-v1.json`, `fixtures/vision/*.png` | 30 original rendered typeset images, six each clear/messy/rotated/ambiguous/adversarial; generated by `scripts/generate-eval-fixtures.py` with Pillow's bundled default font |
| `../docs/screenshots/synthetic-practice.png` | Actual Chromium capture of a disposable synthetic practice session; no learner data |
| `fixtures/work.png` | Original 400×200 white synthetic image with the string `2/5`, created with Pillow for photo UI checks |
| `fixtures/external-v1.json` | Four original external questions; all final answers must remain unverifiable |
| `reports/deterministic.json` | Reproducible exact-math and mock-contract report; no live model quality claim |

Vision cases 25–30 are labeled holdout. These programmatic images test software
and provide a starting live evaluation set; they do not represent human handwriting
or real camera noise. Blurred cases require ambiguity handling, and adversarial
text must be transcribed as content without changing workflow authority.

To regenerate the vision fixtures:
`uv run --project apps/api --locked python scripts/generate-eval-fixtures.py`.
Pillow's bundled font remains under Pillow's applicable distribution licenses;
no font binary is redistributed in this fixture directory.

Runtime model artifacts have separate upstream licenses. The committed browser
manifest contains public repository metadata and hashes only, not the artifacts.
No live evaluation was run. Live reports may be written only from explicitly
authorized synthetic inputs; review them before publishing, even if the inputs
were synthetic. Raw private provider logs never belong here.
